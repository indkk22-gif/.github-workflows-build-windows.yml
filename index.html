Implementation Checklist for Final Windows EXE
The design and basic local color-key / brightness preview are included. The following items need the actual Windows app build before they can be production-secure:
  • Native Windows Hardware ID collection and one-PC binding.
  • Admin-only license signing tool using a protected private key.
  • Customer app signature verification using a public key.
  • Real AI background segmentation and AI clothing replacement model integration.
  • Local database, expiry checks, installer packaging and testing on Windows 10/11.

License activation is intentionally not bypassed by a sample key in this browser prototype. Never embed the administrator's private signing key in the customer application.
